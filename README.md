# Kesari by Bhumika Patel

Luxury fashion house website — Next.js recreation of the Kesari digital flagship.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Google Fonts: Cormorant Garamond, Jost, Great Vibes

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Path | Page |
|------|------|
| `/` | Home — intro splash, Ari–Zardoshi hero, craft showcases, The House |
| `/whats-new` | Season releases |
| `/crafts` | Craft techniques |
| `/crafts/[slug]` | Craft detail |
| `/womenswear` | Womenswear collections |
| `/menswear` | Heritage menswear |
| `/weddings` | The Bridal Room |
| `/atelier` | Write to the house |
| `/world-of-kesari` | A House of Stitch |
| `/product/[slug]` | Product detail |
| `/wishlist` / `/bag` | Wishlist & bag |

Imagery is extracted from the reference recording for fidelity to the original design.
